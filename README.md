# 📰 Portal de Noticias

Aplicación web CRUD desarrollada con Node.js y PostgreSQL.

## 🛠 Tecnologías

- Node.js
- Express
- PostgreSQL
- PUG
- Tailwind CSS
- Zod
- Ajax

## 📋 Requisitos previos

- Node.js instalado
- Laragon con PostgreSQL corriendo
- HeidiSQL o psql para gestionar la base de datos

## 🚀 Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/TuUsuario/portal-noticias.git
cd portal-noticias
```

2. Instalar dependencias

```bash
npm install
```

3. Crear el archivo `.env` en la raíz
   - PORT=3000
   - DB_HOST=localhost
   - DB_PORT=5432
   - DB_USER=postgres
   - DB_PASSWORD=
   - DB_NAME=noticias

4. Iniciar el servidor

```bash
npm run dev
```

5. Abrir en el navegador
   - http://localhost:3000
